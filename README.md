# csharp-katas

Small C#/LINQ/async exercises, each with xUnit tests. Practice repo, not a showcase.

## How it works
Each kata lives in `src/Katas/KataNN_Name/` with its own `README.md` (goal, requirements, acceptance criteria, interview angle).
The implementation is a stub that throws `NotImplementedException`; the tests in `tests/Katas.Tests/` start red. Make them green without editing the tests.

## Run
```bash
dotnet test
```
